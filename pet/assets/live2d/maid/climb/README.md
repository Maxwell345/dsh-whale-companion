# maid 爬墙循环

## 素材状态

- `left/01.png`–`04.png`：从 `maid-climb-left-4-contact-sheet-v3.png` 裁切，1100×1494 RGBA。
- `right/01.png`–`04.png`：当前为 **左侧水平镜像的临时版本**，用于先把左右爬墙流程跑通。
- 右侧不是最终美术：maid 的侧边蝴蝶结、围巾和身体左右不对称细节会被镜像翻转；以后有预算时应独立重画右侧。

左侧 v3 是已接受的原型，仍有手部细节瑕疵：01/02/03 的高位手是张开手掌，04 的高位手更接近拳头。运行时优先保证动作和位置，手型统一留待后续美术修正。

## 运行时

- 每帧 180ms，`01 → 02 → 03 → 04 → 01` 直接切换，不做 alpha 交叉淡化。
- 只对 maid 生效；knit/winter 没有 `climb` 帧时回退旧的 `views.left/right` 程序化攀爬。
- 主进程负责窗口向上移动；角色帧本身不包含整体 Y 位移。
- 窗口贴墙位置由渲染层扫描当前帧的可见轮廓后回传 `wallInset`，主进程按屏幕工作区边缘定位。
